## 3. 三点发现（写进论文 5.6 节）

1. **现象**：本体约束使「类型错」下降约 X%，但「边界错」几乎不变。
2. **原因**：类型是封闭集合，提示词可直接约束；边界是开放判定，依赖模型的语言粒度。
3. **启示**：对本任务，“约束输出空间”比“给更多示例”更划算（P1→P2 的增益小于 P0→P1）。
